# Windows安装依赖

Python3.11、MongoDB、Chromium、Playwright、代理及内置工具由安装包提供。WebView2与.NET离线组件按需安装，校验签名和哈希。数据库旁放置微软VC++运行文件，无需预先安装共享VC++。客户不需要预装开发用Python、Node.js、Docker、WSL或编译环境。

依赖完整性同时覆盖完整安装与签名热更新；卸载不删除系统共享运行库。操作系统本身仍须为受支持的64位Windows10/11，Windows10暂无实机验收。内置工具能力仍按各平台支持矩阵判断。

Microsoft来源与许可：https://learn.microsoft.com/en-us/cpp/windows/redistributing-visual-cpp-files
