## 目标与边界

降低重复监控、重叠请求、大工具结果编码和无输出循环的开销。保留 Web/Celery 并发配置、工具权限、资源池预算、模型上下文预算和既有 60000 字符工具返回窗口。完整原始结果与证据留存路径沿用原行为。本轮没有新增依赖、改 requirements 或重建镜像。

## 实现与原设计变化

| 文件 | 变化与原因 |
| --- | --- |
| `system/log_monitor.py` | 提供跨进程共享 CPU 样本，校验时间与数值；每次 fresh 读数据库，过期、未来时间、NaN、越界值不可作为有效样本。原 get_cpu_percent 仍保留缺失样本时的本地探测。 |
| `workspace/dashboard.py` | 仪表盘复用有效样本，移除正常路径每请求 0.6 秒等待；无样本或旧服务仍使用原本地窗口。原先每个页面独立探测造成重复等待；新增采样来源、时间、年龄字段，旧字段保留。 |
| `ai_pentest/_engine.py` | 常见小结果保留 C JSON 编码路径；大结果按既有窗口生成前缀，避免完整编码后丢弃尾部。有效 JSON 返回前缀与原实现相同，原始结果不修改。另修复 wrapping 每轮被预算判断覆盖的问题：收尾请求在当前循环内保留，人工新指令可解除；不恢复按轮数强制终止有效工作的旧限制。 |
| `frontend/src/composables/useAutoRefresh.ts` | 等待异步刷新结束，拒绝重叠；后台和禁用状态停止定时器，卸载清理。原只捕获同步异常且不等待请求结束。 |
| `frontend/src/pages/dashboard/Dashboard.vue` | 一组数据刷新共用一个在途 Promise，首次、自动、恢复可见状态的刷新互斥，数据仍并行加载。 |
| 相应测试 | 验证共享样本、兜底、两类模型协议、原始结果保留、收尾状态及人工续跑。修复旧仪表盘测试未隔离 Linux loadavg 的不稳定断言。 |

## 实测

VM：原有三 Web 进程、四 Celery 子进程的配置保持不变。下面是短跑结果，不代表全部业务或生产极限吞吐。

| 指标 | 原实现 | 当前测试实现 |
| --- | --- | --- |
| 48 次设备信息请求，12 个客户端并发，错误 | 0 | 0 |
| 设备信息请求中位数 | 731 ms | 188 ms |
| 设备信息请求 P95 | 906 ms | 271 ms |
| 该批请求完成时间 | 3.159 s | 0.818 s |
| 同批简单版本查询 P95 | 35 ms | 63 ms |
| 5 万条模拟接口结果编码的临时内存峰值 | 26.282 MiB | 0.505 MiB |
| 大结果编码时间，启用 tracemalloc | 1.204 s | 0.035 s |
| 小工具结果编码微基准 | 17.6 μs | 37.8 μs |

大结果节省的是编码临时分配，不能说成整机内存下降 98%。小结果增加约 20 μs 的判型成本；简单版本查询短跑存在波动，不能承诺所有请求完全不变，需要在持续同负载测试中继续观察。没有调整任务并发来换取这些结果。

83 项针对本轮改动的回归在 VM 通过，包括当前会话循环、模型协议、用量记录、HTTP 头兼容、监管和监控。旧 test_engine_tools 全量套件含已禁用 collect_js 的旧预期和未隔离 MongoDB 的派发用例，未把它们算作本轮通过证据。

真实前端加载仪表盘，将刷新周期加速到 200ms 并把设备请求延迟 1s，3.5 秒内发生 3 次请求，最大在途数为 1；页面显示 v1.21.167-4；切到后台后请求停止，恢复可见立即刷新且仍无重叠。前端 vue-tsc + Vite 构建通过，产物包含当前测试号。

连续无工具、无实质输出的回归明确验证：两次空响应后仅调用一次收尾，合计 3 次调用完成；收到人工新指令后仍开放工具继续推进。原实现因丢失状态而反复加提示、最终靠上下文接近预算退出，造成额外 CPU 与模型请求成本。

## 兼容、触达与回滚

所有运行变更位于会被分发的 sentinel_platform 和 docker/frontend，下一次获批发布可通过现有热更新链触达存量实例，不依赖覆盖旧 config.yaml。没有创建新的后台采样线程或授权缓存。Web、Worker、Scheduler 需按现有应用流程确认新代码真正生效，不能仅凭源文件已复制就认定所有已导入模块的进程已切换。

测试版本先前临时使用了 168 测试号，用户指出应在当前 167 系列内迭代后已更正，最终为 167-4。此前误发布的 167 已从官网与 GitHub 撤回；167-N 测试代码仅保留本地和 VM。GitHub 上传与正式分发分别需要用户明确批准。

VM 备份位于项目 .update_backup/resource-opt-v1.21.167-4，之前各测试阶段备份也保留。回滚需同时恢复三个后端模块、前端产物和版本文件；仅回滚监控新接口时，仪表盘兼容旧服务并自动走原本地采样。
