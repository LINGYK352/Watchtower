# 文件包含边界评估

## 与路径遍历的区别
路径遍历关注超出允许目录的访问，文件包含还涉及文件被模板引擎或语言运行时解释。先确认输入选择的是静态文件、模板标识还是解释器加载目标；读取文件不等于执行代码。

## 最小验证路径
用客户准备的无执行能力测试文件和正常页面建立基线，记录加载位置、允许根目录及服务端处理方式。优先结合代码审计确认真实包含调用；没有目标侧测试文件或源码时，保留未确认结论，不读取敏感系统文件替代基线。

## 验证与反证
模板错误、内容回显和跳转不证明包含成功；需区分应用直接输出用户输入、普通下载与真实加载文件。远程请求到达受控端也不证明远程内容被解释执行，转 `ssrf` 分别核对请求事实。

## 修复与复测
将可选页面映射为固定服务器模板，禁止用户控制解释器文件路径，限制运行时远程加载能力。复测合法模板、未知标识、越界路径和缓存行为；清理本次测试文件。
