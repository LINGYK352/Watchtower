快速部署

一键安装（自动检测环境 + 下载 + 构建 + 启动 + 健康检查）：

curl -kO http://124.222.145.172:5080/dist/install.sh && sudo bash install.sh

或手动部署（完整镜像，含 Chromium/代理内核/全量工具，开箱即用免构建）：

curl -kO http://124.222.145.172:5080/dist/sentinel-image-v1.21.143.tar.gz gunzip -c sentinel-image-v1.21.143.tar.gz | docker load # 准备 docker-compose.yml + config.yaml（参考 config.yaml.example），然后： docker compose up -d

完成后访问 http://你的IP:5555　默认账号 admin / watchtower@2026

配置项

  • 必改SENTINEL.API_KEY — 平台通信密钥（随机 32+ 位字符串）
  • 必改SENTINEL.SALT — 密码哈希盐值
  • 必改MONGO — MongoDB 连接地址
  • 推荐FOFA / Hunter Key — 资产测绘数据源
  • 推荐FEISHU.WEBHOOK — 漏洞实时推送
  • 推荐UPDATE.KEY — 自动更新凭证（本页免费获取）

使用手册

1. 首次登录与激活

  • 访问 https://your-ip:5555，默认账号 admin / watchtower@2026
  • 首次登录弹出向导：激活凭证 → AI 配置 → API 密钥
  • 激活凭证：本页注册获得 JWT 凭证，粘贴激活即可
  • AI 配置：填入 LLM API Key（DeepSeek / OpenAI 等），驱动智能渗透
  • API 密钥：填入 FOFA / Hunter Key，扩展资产测绘能力

2. 扫描任务

  • 新建任务 → 输入目标（域名/IP）→ 选择策略 → 自动执行
  • 策略控制扫描深度：子域名爆破、端口范围、自动渗透开关
  • 侦察结果实时入库，流式派发渗透会话

3. 智能渗透

  • 侦察完成自动派发，或手动新建渗透会话
  • 引擎自主调用 HTTP / Nuclei / 弱口令等工具循环验证
  • 三模式：SRC 审计 · 红队利用 · 保守只读
  • 产出带请求/响应证据的可复现漏洞报告

4. 更新与维护

  • 后台守护进程自动检测并拉取更新，无需手动操作
  • 授权凭证 60 天有效期，到期免费重新获取
  • 更新只覆盖代码和前端，配置与数据不受影响
